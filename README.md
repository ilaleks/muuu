# muuu

Инструмент для парсинга рыночных лотов с сайта [MU Bless](https://mu.bless.gs/ru/index.php?page=market&serv=server4).

## Установка

Зависимостей, кроме стандартной библиотеки Python 3.11+, не требуется.

## Использование

```bash
python market_scraper.py --server server4
```

Скрипт скачает HTML страницы рынка и выведет найденные предметы в формате JSON. Доступные параметры:

- `--server` — имя сервера (по умолчанию `server4`).
- `--user-agent` — пользовательский User-Agent (по умолчанию маскируется под Chrome).
- `--cookie` — значение заголовка Cookie, если нужен вход в аккаунт.
- `--from-file` — путь до локального HTML-файла (для оффлайн-тестирования парсера без сети).
- `--output` — формат вывода (`json` или `text`).

Пример оффлайн-запуска на тестовом HTML:

```bash
python market_scraper.py --from-file samples/market_sample.html --output text
```

## Тестовый пример

В каталоге [`samples`](samples) лежит файл [`market_sample.html`](samples/market_sample.html) с упрощённой разметкой, по которой можно проверить работу парсера без доступа к сайту.

## Что делать при ошибке 403

Некоторые страницы сайта возвращают 403 Forbidden, если запрос не похож на обычный браузер или требуется авторизация. Попробуйте следующие шаги:

1. Откройте нужную страницу рынка в браузере и убедитесь, что видите лоты.
2. В инструментах разработчика (DevTools) на вкладке **Network** скопируйте заголовок **Cookie** для запроса `index.php?page=market`.
3. Передайте значение в скрипт:

   ```bash
   python market_scraper.py --server server4 --cookie "PHPSESSID=...; other=value"
   ```

4. При необходимости можно указать тот же User-Agent, что использует браузер:

   ```bash
   python market_scraper.py --server server4 --user-agent "<строка из DevTools>"
   ```

Эти заголовки делают запрос неотличимым от реального браузера и помогают обойти блокировку.
